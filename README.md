# BBS Bedrock Launcher

Launcher oficial de **BBS Bedrock Edition**, el cliente para animar en Minecraft Bedrock (también en servidores).

- 🌐 Página web: https://bbs-bedrock.bbs-bedrock-cloudflare.workers.dev
- ⬇️ Descarga: pestaña [Releases](../../releases/latest) → `BBS-Bedrock-Launcher-Setup-x.y.z.exe`

## Requisitos

- Windows 10 u 11 de 64 bits
- Minecraft Bedrock Edition (Microsoft Store / app de Xbox)

Si Windows muestra «Editor desconocido», pulsa **Más información → Ejecutar de todas formas**.

> El cliente BBS está en desarrollo. Proyecto de la comunidad, no afiliado con Mojang Studios ni Microsoft.
